NOËL EN FAMILLE * LYONS-LA-FORÊT
===================================

CONTENU
- index.html : le site web
- supabase-schema.sql : tables, règles d'accès et synchronisation temps réel
- INSTALLATION.txt : ce guide

IMPORTANT
Le site est prêt côté interface, mais il n'est pas encore publié sur Internet et
la base partagée doit être créée. Je ne peux pas créer un compte d'hébergement
ou publier sur un domaine sans accès/autorisation de votre part.

ÉTAPE 1 — CRÉER LA BASE PARTAGÉE
1. Crée un projet sur https://supabase.com/
2. Choisis une région européenne si elle est proposée.
3. Dans le projet, ouvre SQL Editor > New query.
4. Copie-colle tout le contenu de supabase-schema.sql, puis clique Run.
5. Va dans Project Settings > API (ou Connect selon l'interface).
6. Récupère Project URL et la clé publique anon / publishable (jamais la clé
   service_role ou secret).

ÉTAPE 2 — CONNECTER LE SITE
1. Ouvre index.html dans un éditeur de texte.
2. En bas du fichier, repère SUPABASE_URL et SUPABASE_ANON_KEY.
3. Remplace les textes COLLER_ICI... par les valeurs de ton projet.
4. Enregistre index.html.

ÉTAPE 3 — PUBLIER LE SITE
1. Crée un compte sur https://www.netlify.com/
2. Déploie le dossier du site (ou glisse le dossier sur Netlify Drop si cette
   option est disponible dans ton compte).
3. Netlify fournit une adresse publique en https://...netlify.app
4. Envoie ce lien à la famille.

FONCTIONNEMENT
- Les inscriptions, plats et votes sont enregistrés dans la base Supabase.
- Les changements sont synchronisés en temps réel entre les visiteurs.
- Aucun e-mail, compte ou mot de passe n'est demandé aux participants.

À SAVOIR SUR LE MODE « OPEN »
Le mode ouvert signifie que toute personne possédant le lien peut lire les noms,
ajouter des inscriptions et des plats, et modifier les votes. Le pseudo choisi
n'est pas une authentification : un visiteur peut voter en se faisant passer
pour quelqu'un d'autre. N'envoie donc pas le lien publiquement si les noms de
famille doivent rester privés. Pour une vraie protection des votes, il faudrait
au minimum un code commun ou une authentification.

CONFIDENTIALITÉ
Le site affiche les noms et prénoms derrière les pseudos à tous les visiteurs.
Ne collecte que les informations nécessaires et supprime le projet après les
fêtes si tu n'en as plus besoin. Prévois aussi un moyen de supprimer les données
sur demande des participants.
